# 装卸月台看板

晚班到货车辆统一排口的拖拽看板：把待排车辆拖进月台，系统自动校验排口规则，被挡车辆回到待排区并标明未通过条件。

- 行业：物流
- 技术栈：React、Vite、TypeScript、dnd-kit
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能

- 车辆预约：承运商、到车时间、货温（常温/冷藏/冷冻）、预计占用分钟
- 月台资料：可接货温、下一次检修时间
- 拖入校验：同月台前后车至少留 10 分钟；冷链车不能进常温口；占用结束不能超过检修开始时间
- 被挡车辆回到待排区，卡片上标出具体未通过的条件
- 车辆到达后锁定月台；改口需登记原因和实际到车时间，原时段立即释放
- 已完成车辆只保留在历史区（含改口登记记录）

## 代码结构（分开维护）

- `src/data/docks.ts` — 月台资料（可接货温、检修计划）
- `src/rules.ts` — 预约规则（间隔分钟数、冷链口径、校验逻辑与文案）
- `src/App.tsx` — 看板页面
- `src/data/appointments.ts` — 演示预约数据；正式数据保存在浏览器 localStorage（key：`hxwlfront-14-dock-board`）
